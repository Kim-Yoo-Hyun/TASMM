# Insights

## Facts

- OpenIN explicitly addresses moved target instances.
- It uses carrier relationships to update scene representation.

## Paper Claims

- Dynamic relationship updates improve instance-oriented navigation.

## Inferences

- Staleness can be relational, not only temporal.
- CAND-001 should compare against relation-only memory and ask whether task intent improves when to verify relations.

## Connection to Field Trends

- Strong example of 2025 shift from static open-vocabulary maps to dynamic household memory.

## Possible Contribution Angles

- Generalize staleness beyond carrier relationships.
- Add human instruction ambiguity and correction to dynamic instance memory.

## What Would Change This Assessment

- If OpenIN's benchmark is easy to reuse, it may become the first experiment substrate.
