# Insights

## Facts

- LangMap separates goal navigation by semantic hierarchy.
- It is a benchmark, not a semantic map method.

## Paper Claims

- Multi-granularity open-vocabulary navigation is under-evaluated.

## Inferences

- Our survey should not treat "object grounding" as the only semantic map task.
- Granularity and staleness can be combined: stale instance memory may require fallback to region/room-level search.

## Connection to Field Trends

- Represents 2026 benchmark-driven movement toward hierarchy.

## Possible Contribution Angles

- Hierarchical fallback when instance memory is stale.
- Task-driven selection of instance vs region vs room map query.

## What Would Change This Assessment

- If LangMap has no accessible implementation, use it as framing rather than first benchmark.
