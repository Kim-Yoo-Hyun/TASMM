# results

This folder stores lightweight result summaries, tables, and log summaries for sharing.

Rules:

- Keep only small Markdown/CSV/JSON summaries that are useful for reading or paper planning.
- Do not store raw detector outputs, generated JSONL tables, RGB-D frames, checkpoints, model caches, or full logs here.
- Full generated experiment outputs are reproducible from `experiments/*/tools/` and ignored by default.
